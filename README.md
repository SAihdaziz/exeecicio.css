# Exercicio CSS 💻🎨

Este projeto é um exercício de prática com HTML e CSS, com o objetivo de aplicar estilos visuais e testar responsividade.

## 🛠️ Tecnologias usadas

- HTML5
- CSS3
- Visual Studio Code

## 📱 Responsividade

O site foi pensado para se adaptar a diferentes tamanhos de tela (mobile, tablet e desktop).

## ✨ Funcionalidades

- Estilização de layout com CSS
- Responsividade com media queries
- Efeitos visuais com transições e hover

## 🔧 Em desenvolvimento

## 🚀 Como visualizar

Você pode abrir o arquivo `index.html` direto no navegador ou publicar com GitHub Pages ou Netlify (posso te ajudar com isso também).
